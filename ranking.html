Ranking

Proteins ranked by how consistently they fall (or rise) when the EMC is perturbed, across every dataset that measured them. Each dataset contributes one value: the size of the change on a common scale, damped when its p-value is weak, and weighted by how complete the dataset is and how confident the orthologue is. A protein ranks highly only if several datasets agree. EMC subunits are ranked too, except for the subunit perturbed in each dataset. How the score is calculated
